# Shell (Bash)

**Bash scripting basics: init files, variables, expansions, I/O redirection and filters.**

Holberton School × Tuwaiq Academy, Advanced Software Engineering track.

| Folder | What it covers |
|---|---|
| `init_files_variables_and_expansions` | Aliases, PATH, local and global variables, arithmetic and base conversions |
| `io_redirections_and_filters` | Redirection, pipes and text filters |

Every script runs on Ubuntu with `#!/bin/bash`.
